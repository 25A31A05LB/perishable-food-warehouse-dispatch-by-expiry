
# Perishable Food Warehouse Dispatch System

## About the Project
The Perishable Food Warehouse Dispatch System is a Java-based application that helps manage perishable food items in a warehouse. It uses the Min-Heap data structure to prioritize food items according to their expiry dates.

The system dispatches food items with the nearest expiry dates first, helping reduce food wastage and improve inventory management.

## Features
- Add food items.
- View warehouse inventory.
- Manage food batches.
- Prioritize items based on expiry dates.
- Dispatch items with the earliest expiry date first.
- Validate expiry dates.

## Technologies Used
- Java
- Data Structures and Algorithms
- Min-Heap
- Object-Oriented Programming

## Objective
To reduce food wastage and improve warehouse efficiency by dispatching perishable food items based on their expiry dates.
