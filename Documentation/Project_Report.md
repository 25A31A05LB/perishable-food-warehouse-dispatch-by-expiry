# PROJECT REPORT
# PERISHABLE FOOD WAREHOUSE DISPATCH SYSTEM

## 1. Introduction
The Perishable Food Warehouse Dispatch System is a Java-based application developed to manage food products that have expiry dates.

In warehouses, some food products expire earlier than others. This project uses a Min-Heap data structure to dispatch food batches with the earliest expiry dates first.

## 2. Problem Statement
Managing perishable food products manually can cause delays and food wastage. Therefore, an automated system is required to organize food batches and dispatch them according to expiry dates.

- To reduce food wastage.
