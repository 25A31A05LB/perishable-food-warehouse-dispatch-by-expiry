# Abstract

The Perishable Food Warehouse Dispatch System is a Java-based application used to manage food items that have expiry dates.

The main purpose of this project is to reduce food wastage by dispatching food items based on their expiry dates. It uses the **Min-Heap data structure** to select the food batch with the earliest expiry date first.

The system allows users to:
- Add food batches.
- View available food inventory.
- Check food expiry dates.
- Dispatch food batches based on expiry dates.
- Prevent the addition of already expired food.

This project uses Java programming, Object-Oriented Programming (OOP), and Data Structures.

The system helps improve warehouse management, reduces food wastage, and makes food dispatching easier and faster.
